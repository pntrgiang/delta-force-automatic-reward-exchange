# code Delta Force đã xác minh

danh sách code sự kiện Delta Force đã được xác minh, dùng với extension [đổi code delta force](../README.md).

## cách dùng

1. bấm nút **copy** ở góc phải mỗi khối code bên dưới để chép cả nhóm.
2. mở extension, dán vào ô **danh sách code** rồi bấm **bắt đầu**.

không cần tải file, không cần giải nén — dán thẳng từ trang này là được. mỗi khối chỉ chứa code, dán cả đoạn có tiêu đề cũng không sao vì extension tự lọc bỏ phần không phải code.

lưu ý: code sự kiện thường có hạn dùng hoặc giới hạn số lượt đổi, nhóm càng cũ càng dễ gặp code đã hết hạn/hết lượt — đó là bình thường, không phải lỗi.
